📥 Download & Installation

Step 1 — Install StimTake Ultimate

DOWNLOAD STIMTAKE ULTIMATE 2.7.4 FOR WINDOWS

Download the Windows installer.

Close any previous version of StimTake.

Run the installer.

Launch StimTake Ultimate.

Step 2 — Install the Chaturbate Companion App

The StimTake Studio companion app is required for the associated live Chaturbate integration.

GET THE FREE CHATURBATE COMPANION APP

Add the app to your broadcasting room and start it.

Step 3 — Connect Your Broadcasting Room

Generate your Private Events API URL through the official Chaturbate API token page.

Open the Chaturbate connection section in StimTake Ultimate.

Enter your Private Events API URL.

Connect your room.

Configure your OBS Browser Source using the URL displayed inside StimTake Ultimate.

Generate Your Chaturbate API Token

Never share your Private Events API URL with anyone.

Step 4 — Import Your Free Starter Packs

NEW IN VERSION 2.7.4

Download the Monkey & Banana Pack or Iris Moonshine Pack.

Leave the downloaded pack as a ZIP file.

Open StimTake Ultimate.

Navigate to the Studio workspace.

Select Import ZIP (Overlay / Full Pack) or use Restore from file / Import pack.

Select your downloaded ZIP.

Import the complete collection into a new workspace.

Review your imported overlay assignments.

Configure or review your tip triggers.

Test your animations before going live.

You can also import individual ZIP overlays into your selected slot.

Step 5 — Create Your Own Games

Visit the free online game builders, customize your prizes and animations, download your generated HTML file, and import it into StimTake Ultimate.

Make your broadcast your own!
