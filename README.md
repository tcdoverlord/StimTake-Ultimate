# StimTake Ultimate

**Built by a broadcaster, for broadcasters.**

Free Windows broadcasting software for interactive OBS overlays, automated tip effects and personalized viewer management. No purchase or subscription is required for this release.

[**Download StimTake Ultimate for Windows**](https://github.com/tcdoverlord/StimTake-Ultimate/releases/latest)

## Features

- 20 overlay slots with custom HTML and supporting media assets, managed through a single OBS Browser Source.
- 20 independent tip automation rules with configurable token ranges and duration.
- Native Chaturbate Events API integration.
- Viewer Intelligence: saved viewer profiles, personalized welcome drafts and private reminders.
- Private arrival notifications with a sequential queue, All named viewers and Personalized profiles / VIPs modes.
- Viewer counters, filtering, sorting, bulk selection and protected deletion confirmation.
- Automatic viewer saving controls, persistent workspaces and backup/restore.

## Installation

1. Open [Releases](https://github.com/tcdoverlord/StimTake-Ultimate/releases) and download the `.exe` installer under **Assets** (not the auto-generated source archives).
2. Run the installer and launch StimTake Studio (the installed application name).
3. Read the [Quick Start](QUICK-START.md) for OBS and Chaturbate setup.

**Requirements:** Windows 10 or 11 on an x64-compatible system; OBS Studio for overlay rendering; internet access for Chaturbate integration and any required WebView2 download. The setup includes the Microsoft Visual C++ x64 runtime prerequisite and can download WebView2 when needed.
