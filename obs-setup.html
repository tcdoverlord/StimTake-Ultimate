01

Open StimTake Ultimate

Launch StimTake Ultimate 2.7.4, choose your preferred Studio workspace and keep the application running while using OBS.

New to StimTake? Download the free desktop application and starter packs.
02

Add a Browser Source

  1. Open OBS Studio and select your broadcasting scene.
  2. Click the + button under Sources.
  3. Choose Browser.
  4. Name the source StimTake Ultimate, then click OK.

03

Configure the source

Leave Local file unchecked. Paste the URL above into the URL field and set Width to 1920 and Height to 1080.

Enable Control audio via OBS if you want to manage overlay sound in the OBS Audio Mixer. A custom frame rate of 60 FPS is recommended; 30 FPS is also an option if performance is limited.

Leave the shutdown and refresh options unchecked to avoid unnecessary source restarts when switching scenes.

Click OK to save the Browser Source properties.

04

Position the overlay

Move StimTake Ultimate above your camera and other background sources in the OBS Sources list.

  1. Right-click your StimTake Ultimate source.
  2. Select Transform → Fit to screen (or press Ctrl + F with the source selected).
  3. Make sure the source is visible. Lock it to prevent accidental movement.

Quick fixes

Something not working?

Nothing appears in OBS

Confirm StimTake Ultimate is running, the Browser Source URL is correct, its visibility is enabled and a slot is actively playing. Check that the source is above your webcam. You can open the local URL in your browser to check whether the local server responds.

My animation is cut off or too small

Check the source dimensions are 1920 × 1080, then select Transform → Fit to screen. Individual overlay files may have their own positioning settings.

I cannot hear animation audio

Check Control audio via OBS, the OBS Audio Mixer mute status and volume, and the overlay's own audio settings. Confirm the imported overlay actually includes sound.

Do I need a new Browser Source for every overlay?

No. All assigned overlays in the active StimTake workspace use the same OBS Browser Source.

Why are tips not triggering effects?

Check your Chaturbate Events API connection and configured tip rules. Install and start the StimTake Studio companion app in your room for the associated integration. Never share your private Events API URL.
