Step 01

Install and open both applications.

  1. Download OBS Studio for Windows from the official OBS website, if you do not already have it.
  2. Download the StimTake You Windows installer from GitHub Releases.
  3. Run the installer and launch StimTake You from the Start menu.
  4. Open OBS Studio and select or create a scene.
Download OBS Studio ↗Release notes ↗

Use Windows 10 or 11, 64-bit. The installer may need internet access to install missing prerequisites.

Step 02

Add a Browser Source.

  1. Find the Sources panel in OBS.
  2. Click the + button.
  3. Select Browser.
  4. Choose Create new and name it StimTake You.
  5. Click OK.

Step 03

Configure the browser source.

  1. Leave Local file unchecked.
  2. Paste the StimTake You URL from above.
  3. Set Width to 1920 and Height to 1080.
  4. Enable Control audio via OBS if you want to manage overlay sounds in the OBS mixer.
  5. Optionally enable custom frame rate and choose 60 FPS (or 30 FPS for lower resource use).
  6. Leave both shutdown-on-hide and refresh-on-scene-activation unchecked to avoid unnecessary restarts.
  7. Click OK.

Step 04

Place the overlay above your content.

Drag StimTake You to the top of the OBS Sources list, above the camera, game or display capture you want it to overlay.

Right-click StimTake You → Transform → Fit to Screen, or select the source and press Ctrl + F. For a standard 1920 × 1080 canvas this fills the scene. For other canvas shapes, adjust the transform as needed to preserve the aspect ratio.

Lock the source after positioning it to avoid accidental movement.

Step 05

Import and test your first effect.

  1. Return to StimTake You and open a workspace.
  2. Choose a slot in edit mode.
  3. Need a first overlay? Open one of the four free game builders, customize the choices, preview and download the standalone HTML file.
  4. Select Import HTML / Media File, Import Overlay Folder, or Import ZIP (Overlay / Full Pack).
  5. For a supported full portable deck ZIP, use Import ZIP or Restore from file / Import pack to create a new workspace.
  6. Select your imported workspace or slot and turn on click mode.
  7. Click the assigned overlay slot and check the OBS preview. Use Stop selected or Stop all to clear it.

When nothing is playing, the overlay browser source should be transparent. Some imported HTML or media can have its own opaque background.

Tip: In-app shortcuts Alt+1 through Alt+0 trigger slots 1–10; Alt+Shift+1 through Alt+Shift+0 trigger slots 11–20. Escape stops all overlays in the current workspace. Click mode must be enabled and the Studio focused.

Step 06

Keep the studio running in the background.

Minimize or click X to hide StimTake You to the Windows notification area. The OBS server stays running. Look for the green Y icon under the hidden-icons arrow if it is not visible.

Left-click the icon to reopen the app. Right-click and choose Exit when you want to fully close it. Exiting stops the OBS connection.

Troubleshooting

Something not displaying?

The OBS source is blank.

Check that StimTake You is running, the address uses port 8796, Local file is unchecked and the source is visible above your background. Turn on click mode and trigger an overlay. A transparent source is normal when idle.

OBS shows a connection error.

Open StimTake You and confirm the local server is ready. Try opening http://127.0.0.1:8796/obs.html in a browser on the same computer. If the app reports a port conflict, close the other process using that port and restart StimTake You. In OBS, use Refresh cache of current page if needed.

There is no overlay sound.

Enable Control audio via OBS and check the Audio Mixer for the source. Confirm it is not muted and that the imported asset contains supported audio. Browser autoplay restrictions or codec support may also affect playback.

My imported media has a solid background.

Transparency must be present in the original asset or its HTML wrapper. A normal MP4 with a solid background does not automatically become transparent. Use compatible alpha-enabled WebM or HTML overlays.

The app will not launch a second time.

Check the notification area for the green Y icon. StimTake You prevents duplicate instances to protect workspace files and the local server.

How do I restore a full backup?

Use Restore backup in the application's backup controls. Select a supported full backup ZIP and confirm. The app validates and stages the data, then exits completely. Reopen StimTake You to complete restoration. Deck-only JSON backups do not include every asset.
