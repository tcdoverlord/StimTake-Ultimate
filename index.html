Good to know

Frequently asked questions.

Is it really free?

Yes. StimTake Ultimate is distributed free of charge as proprietary software. No subscription or purchase is required for this release.

Do I need OBS?

OBS Studio is needed for the overlay integration. Configure the supported platform connection for live event features.

Can I share the download?

Share this website or the official release page so other broadcasters can find the current installer.

How can I report a problem?

Open an issue on GitHub. Please redact credentials and private viewer information from logs or screenshots.

How do I verify the installer?

The official v2.7.3 installer is served by GitHub Releases. SHA-256: 6b1fd82dc6ea6e0636276038ac0bb0bc3c73798f1179185e44be433f5b37992e. Check that the file matches this checksum. This checksum verifies file identity, not software safety.
